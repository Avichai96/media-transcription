# Module-level functions, 2026-11-17

## `src/app/core/startup/middlewares.py::add_middlewares`

main.py calls it once with the app; a class would hold nothing.

## `scripts/local.py::build`

`uv run local-build` runs it through [project.scripts], which names a function, not a class.

## `scripts/local.py::run`

`uv run local-run` runs it through [project.scripts], which names a function, not a class.

## `scripts/local.py::_compose`

The one step build and run share, which hands the process to docker compose; it holds no state for a class to keep.

## `scripts/format.py::main`

`uv run format` runs it through [project.scripts], which names a function, not a class.

## `scripts/rules.py::main`

`python -m scripts.rules` runs it; it only turns the count Rules returns into the exit code.
